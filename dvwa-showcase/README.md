# DVWA Security Assessment Website

Open `index.html` in a browser.

## Edit content
- Update module text, payloads, and image paths in `js/data.js`.
- Add screenshots inside `assets/screenshots/`.
- Replace the profile image at `assets/profile/safayet-ullah.jpg`.

## Files
- `index.html` — page layout
- `css/style.css` — design and responsive layout
- `js/data.js` — project content
- `js/script.js` — navigation, carousel, copy buttons, image preview
