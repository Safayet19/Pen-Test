# Penetration Testing Project

A short cybersecurity project created as part of a Government Project in Bangladesh, focused on practical penetration testing, vulnerability assessment, and security documentation.

This repository contains a web-based project showcase with testing evidence, screenshots, and summarized findings from a controlled lab environment.

## Live Project

View the project here:

[https://safayet19.github.io/Pen-Test/dvwa-showcase/](https://safayet19.github.io/Pen-Test/dvwa-showcase/)

## Project Focus

- Penetration testing practice
- Web application vulnerability assessment
- Security testing documentation
- Evidence-based reporting
- Controlled lab testing environment

The DVWA testing project is included as a practical lab-based demonstration of common web security vulnerabilities.
