A cybersecurity project showcasing DVWA vulnerability testing in a controlled lab environment. This project includes practical testing of common web application vulnerabilities such as Brute Force, Command Injection, CSRF, File Inclusion, File Upload, SQL Injection, and XSS. Each module presents the tested payloads, evidence screenshots, observed results, and concise findings to demonstrate the impact of insecure web application design and the importance of proper security controls.
